# Mis Proyectos Python

Repositorio único que agrupa mis proyectos de desarrollo en Python. Cada proyecto es una subcarpeta con su propio historial de commits, integrada con `git subtree`.

## Proyectos

- **[Task-Manager-API](Task-Manager-API)** — Administrador de tareas con SQLAlchemy y FastAPI.
- **[URL-Shortener-API](URL-Shortener-API)** — API que recibe una URL larga, la limpia (valida, normaliza) y devuelve un código único para redirigir con un 301.
- **[API-de-Autenticacion-con-JWT](API-de-Autenticacion-con-JWT)** — API de autenticación con FastAPI y JWT: registro, login, perfil y roles de acceso. Usa PostgreSQL, bcrypt y roles.
- **[Dashboard-UCI-Adultos-2025](Dashboard-UCI-Adultos-2025)** — Dashboard en Python para reflejar datos clínicos.

## Cómo clonar

```bash
git clone https://github.com/acamilox/Mis-Proyectos-Python.git
```

Cada subcarpeta conserva la historia de commits completa del proyecto original (integrada con `git subtree add`).
